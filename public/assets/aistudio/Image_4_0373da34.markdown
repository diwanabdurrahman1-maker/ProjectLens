## Brand & Style

This design system establishes an analytical, high-precision environment tailored for founders, product strategists, and engineering leaders evaluating complex project viability. The design aesthetic is grounded in a deep-space dark SaaS paradigm, blending subtle glassmorphism with high-energy neon violet and electric cyan accents.

### Visual Archetype
- **Aesthetic Movement:** Precision Dark SaaS with Frosted Glass accents.
- **Tone:** Methodical, visionary, perceptive, and focused.
- **Atmosphere:** Deep navy backdrops paired with translucent layered surfaces eliminate eye fatigue during heavy data consumption, while focused luminous accents guide attention strictly to high-value insights, viability scores, and risk matrices.

## Colors

The palette balances dark navy foundations with high-clarity neon signals to support AI-driven project insights.

### Functional Roles
- **Primary (`#8B5CF6`)**: Primary CTAs, active operational states, focused inputs, and core analytical highlights.
- **Secondary (`#06B6D4`)**: Success validation metrics, high-confidence scores, auxiliary active tabs, and secondary progress markers.
- **Tertiary (`#A855F7`)**: Radiant gradients, AI-generation badges, and visual depth glows.
- **Neutral Base (`#070B19`)**: Base canvas surface, absorbing screen reflection and creating an infinite canvas feel.

### Surface System
- **Canvas Base**: `#070B19`
- **Surface Elevation 1 (Containers)**: `#0D1326` (or `rgba(13, 19, 38, 0.7)` when frosted)
- **Surface Elevation 2 (Cards, Flyouts)**: `#141D38` (or `rgba(20, 29, 56, 0.6)`)
- **Surface Elevation 3 (Overlays, Modals)**: `#1E2B52`
- **Translucent Borders**: `rgba(255, 255, 255, 0.08)` to `rgba(139, 92, 246, 0.2)`
- **Text Primary**: `#F8FAFC`
- **Text Secondary**: `#94A3B8`
- **Text Muted**: `#64748B`

## Typography

Typography prioritizes pure utilitarian clarity and scanning speed. Using Inter across headlines, body copy, and analytical data tags enforces an uncompromised structural grid.

- **Headlines**: Tight letter-spacing (`-0.015em` to `-0.025em`) ensures prominent headings remain compact and assertive.
- **Numbers & Metrics**: Tabular figures (`font-variant-numeric: tabular-nums`) must be applied across all scorecards, comparative percentage meters, and financial output panels.
- **Micro-Labels**: Always rendered in medium or semi-bold weights with slight letter-tracking for rapid decipherability over dark glass containers.

## Layout & Spacing

A fluid 12-column grid system drives dashboard modules, risk matrices, and comparative feasibility panes.

### Breakpoints & Adaptive Rules
- **Desktop (1280px+)**: 12 columns, 24px gutters, 32px canvas margins. Sidebars and toolbars remain dock-anchored.
- **Tablet (768px - 1279px)**: 8 columns, 20px gutters, 24px canvas margins. Multi-metric insight grids compress to 2 columns.
- **Mobile (< 768px)**: 4 columns, 16px gutters, 16px canvas margins. Side navigation transitions to an off-canvas drawer; metric cards stack linearly.

Spacing inside cards maintains a strict 16px (`space-md`) or 24px (`space-lg`) internal breathing perimeter to preserve visual independence between glass panes.

## Elevation & Depth

Visual hierarchy uses frosted glassmorphic layering combined with calibrated spectral glows rather than traditional murky drop shadows.

### Elevation Architecture
1. **Level 0 (Canvas)**: Non-reflective `#070B19` ground plane.
2. **Level 1 (Sub-Containers & Grid Panels)**: Background `rgba(13, 19, 38, 0.75)`, backdrop blur `12px`, outline `1px solid rgba(255, 255, 255, 0.05)`.
3. **Level 2 (Interactive Cards & Navbars)**: Background `rgba(20, 29, 56, 0.65)`, backdrop blur `16px`, outline `1px solid rgba(255, 255, 255, 0.08)`. Shadow: `0 8px 32px rgba(0, 0, 0, 0.35)`.
4. **Level 3 (Modals, Context Menus, Hover States)**: Background `rgba(30, 43, 82, 0.85)`, backdrop blur `24px`, outline `1px solid rgba(139, 92, 246, 0.3)`. Shadow: `0 12px 40px rgba(7, 11, 25, 0.7), 0 0 20px rgba(139, 92, 246, 0.15)`.

### Ambient Glows
Dynamic highlights leverage soft radial gradients positioned under critical insights (e.g., an 80px blurred disk with `rgba(139, 92, 246, 0.12)` or `rgba(6, 182, 212, 0.1)`), delivering subtle futuristic depth without muddying contrast.

## Shapes

The design system employs a balanced `roundedness: 2` geometry. This creates an engineered, software-grade feel that avoids overly playful circularity while keeping borders soft and modern.

### Corner Radius Scale
- **Base UI Elements (`rounded`)**: `0.5rem` (8px) - Form inputs, standard buttons, dropdown menus, chips, and table headers.
- **Containers & Panels (`rounded-lg`)**: `1rem` (16px) - Analysis cards, modal windows, tab groups, and data visualization viewports.
- **Hero Containers (`rounded-xl`)**: `1.5rem` (24px) - Master preview canvases and featured report cards.
- **Pill Elements**: `9999px` strictly reserved for status indicators, confidence tags, and user avatars.

## Components

### Buttons
- **Primary**: Solid gradient background from `#8B5CF6` to `#A855F7`, white text (`#F8FAFC`), subtle inset border highlight `1px solid rgba(255, 255, 255, 0.25)`. Hover: 15% brighter with cyan-tinted drop glow `0 0 16px rgba(139, 92, 246, 0.4)`. Radius: `0.5rem`.
- **Secondary (Glass)**: Background `rgba(20, 29, 56, 0.6)`, text `#F8FAFC`, border `1px solid rgba(255, 255, 255, 0.1)`. Hover: `rgba(20, 29, 56, 0.9)`, border `rgba(139, 92, 246, 0.4)`.
- **Tertiary / Ghost**: Transparent background, text `#94A3B8`. Hover: Text `#F8FAFC`, background `rgba(255, 255, 255, 0.05)`.

### Cards & Panels
- Constructed with backdrop-filtered dark glass (`backdrop-filter: blur(16px)`).
- Bound by a hairline border (`1px solid rgba(255, 255, 255, 0.08)`).
- When highlighted or active, the border shifts to a dual-stop linear gradient (`rgba(139, 92, 246, 0.5)` to `rgba(6, 182, 212, 0.5)`).

### Input Fields
- Background `rgba(7, 11, 25, 0.8)`, border `1px solid rgba(255, 255, 255, 0.12)`, radius `0.5rem`.
- Focus state: Border color changes to `#8B5CF6` with a soft outer glow ring (`box-shadow: 0 0 0 3px rgba(139, 92, 246, 0.2)`).
- Placeholder text: `#64748B`.

### Badges & Status Chips
- Pill-shaped (`9999px`).
- **AI / Viability Score**: Background `rgba(139, 92, 246, 0.15)`, text `#C4B5FD`, border `1px solid rgba(139, 92, 246, 0.3)`.
- **Positive / Validated**: Background `rgba(6, 182, 212, 0.15)`, text `#67E8F9`, border `1px solid rgba(6, 182, 212, 0.3)`.
- Compact padding: 4px vertical, 10px horizontal; typography uses `label-sm` or `label-md`.

### Navigation Tabs
- Sleek segmented pill or underlined tabs.
- Segmented container uses `rgba(7, 11, 25, 0.6)` with 4px padding.
- Active tab features a floating glass surface (`rgba(20, 29, 56, 0.9)`), crisp white text, and a tiny cyan indicator pip or gradient top border.

### Checkboxes & Radio Controls
- Base: `1px solid rgba(255, 255, 255, 0.2)`, background `rgba(13, 19, 38, 0.8)`. Radius: 4px for checkboxes, 50% for radios.
- Checked: Background `#8B5CF6`, border `#8B5CF6`, inner icon or dot in pure white.
